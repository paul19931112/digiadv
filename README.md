# 數碼冒險：肉鴿版（非官方粉絲同人作品）

數碼寶貝風格的肉鴿（Roguelike）卡牌冒險遊戲：行動條＋卡牌戰鬥、三段進化、勸降夥伴、分支劇情與多重結局。
電腦、手機（直向／橫向）都能玩，手機上可以「加入主畫面」當成 App 使用。

目前版本：v16.9（更新內容請看 [更新紀錄.md](更新紀錄.md)）

## 怎麼玩
- 線上遊玩：部署到 GitHub Pages 後的網址（例如 `https://你的帳號.github.io/repository名稱/`）
- 本機遊玩：下載後直接雙擊 `index.html`
- 詳細規則請看 [遊戲說明.txt](遊戲說明.txt)，遊戲內也有新手教學與「❓ 說明」
